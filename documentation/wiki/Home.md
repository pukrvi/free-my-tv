# Vibe TV

**No Ads, No Bloat, Only Vibes.**

A remote-first Android TV home, built on Free My TV. Start with the [installation guide](https://github.com/pukrvi/vibe-tv/wiki/Getting-Started), check [your hardware and apps](https://github.com/pukrvi/vibe-tv/wiki/Hardware-and-Apps), or [contribute](https://github.com/pukrvi/vibe-tv/wiki/Contributing).
